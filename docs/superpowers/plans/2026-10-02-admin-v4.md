# Admin v4 (padrão Tribunais, adaptado ao OAB) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (execução nativa nesta sessão, por pedido de custo baixo) ou superpowers:subagent-driven-development. Steps usam checkbox (`- [ ]`).

**Goal:** Dar ao `/admin` as funcionalidades do admin do Tribunais, adaptadas ao OAB: detalhe do lead com o diagnóstico completo formatado, página de Analytics, "Abrir no WhatsApp", links copiáveis e lista enriquecida.

**Architecture:** O serviço Python ganha `POST /diagnostico/html` (mesmo `build_html` do PDF, sem Chromium); o Next o busca no servidor e o exibe num `iframe` com `sandbox` + `srcdoc`. As agregações do Analytics são funções puras testadas (`lib/adminAnalytics.ts`) sobre até 5000 sessões lidas em páginas do repositório; os gráficos são componentes SVG/CSS portados do Tribunais com os tokens do OAB.

**Tech Stack:** Next.js 16 / React 19 / Tailwind v4 (tokens `brand-*`), `lucide-react` (novo), Vitest, FastAPI + pytest.

**Spec:** [`docs/superpowers/specs/2026-09-30-quiz-oab-design.md`](../specs/2026-09-30-quiz-oab-design.md) §12 (e `DESIGN.md`).

## Global Constraints

- Visual só com os tokens/componentes de `DESIGN.md` e `components/admin/ui.tsx`: cartões 14px só com borda, botões 16px, campos 12px, selos em pílula; **sem sombra em cartão/gráfico**; sem `slate-*`/`gray-*`; Poppins.
- Um botão primário (amarelo) por tela. Estados em `Badge`/`Pill` (verde só para "pronto/concluído", vermelho só para erro).
- Nenhum texto do diagnóstico é duplicado no app: o HTML vem do serviço Python (pacote do VDE).
- O HTML do diagnóstico é renderizado só em `iframe sandbox` (sem `allow-scripts`, sem `allow-same-origin`).
- Telefone do lead só em links `wa.me` montados no servidor/cliente do admin (página já protegida por login); nada novo em endpoints públicos.
- Rotas/páginas do admin continuam protegidas por `proxy.ts` e pela checagem de sessão do layout; `export const dynamic = 'force-dynamic'` na página de Analytics.
- Commits terminam com `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`; commit local, sem `git push`.
